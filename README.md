# Senol Dogan

Full stack developer in Oulu, Finland. Eight years in software — since 2018, first in Turkey, since 2022 in Finland.

I build web and mobile products end to end: React and TypeScript in the front, Node.js and PostgreSQL behind, React Native when the product needs an app. Lately most of my work is AI tooling — MCP servers, agent workflows, and the tests that keep generated code honest.

- **[Gistsmith](https://gistsmith.com/)** — Gistsmith transcribes the conversation live, translates it if you like, and has your note ready when the meeting ends: your tasks first, then decisions and a summary. No bot joins the call, and no one else in the meeting needs to install anything..
- **[LLM-Context-Manager](https://github.com/senoldogann/LLM-Context-Manager)** — a code graph for AI coding agents. Rust, MCP, published on npm as `@senoldogann/context-manager`. 61 stars.
- **[Guardian](https://guardianide.com)** — desktop app that watches a codebase and flags architectural drift in AI-written code. TypeScript, Rust, Tauri.
- **[JobFinder.fi](https://www.jobfinder.fi)** — Finnish job search that pulls several sources into one view. Next.js SSR, Go, PostgreSQL, Elasticsearch.
- **[OmaLeima](https://www.omaleima.fi)** — digital stamp pass for student events. React Native, Next.js, Supabase.
- **11 iOS apps** on the [App Store](https://apps.apple.com/developer/id1811382419), including Code Companion Mobile and OmaLeima.
